# Заметки

Адаптивное SPA-приложение для заметок со списками задач. Проект выполнен на Nuxt 4, Composition API и TypeScript в строгом режиме.

## Возможности

- создание, изменение и удаление заметок;
- добавление, изменение, удаление и отметка задач;
- undo/redo с лимитом 50 операций без хранения полных копий заметки;
- объединение непрерывного текстового ввода в одну операцию;
- восстановление несохранённого черновика после перезагрузки;
- ручная синхронизация Pinia с localStorage;
- обработка изменений, сделанных в другой вкладке;
- доступные модальные окна с focus-trap и закрытием по Escape;
- адаптивные desktop/mobile интерфейсы;
- unit-тесты истории, хранилища и store.

## Стек

- Nuxt 4.5.2;
- Vue 3 и Composition API;
- TypeScript strict;
- Pinia;
- SCSS;
- Vitest;
- npm;
- Docker.

## Требования

- Node.js 22 или новее;
- npm 11 или совместимая версия.

## Установка и запуск

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу `http://localhost:3000`.

## Проверки

```bash
# Строгая проверка TypeScript
npm run typecheck

# Unit-тесты
npm test

# Отчёт о покрытии
npm run coverage

# Production-сборка
npm run build
```

Названия тестов и комментарии в исходном коде написаны на русском языке.

## Запуск в Docker

```bash
docker compose up --build
```

Для совместимости также можно использовать:

```bash
docker-compose up --build
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Маршруты

- `/` — список заметок;
- `/notes/new` — создание заметки;
- `/notes/:id` — редактирование заметки.

Создание и редактирование используют один экран и общую бизнес-логику.

## Хранение данных

Сохранённые заметки и черновики находятся в localStorage. Данные содержат `schemaVersion`. Запись выполняется с задержкой, а не при каждом нажатии клавиши.

История undo/redo существует только в текущей сессии редактора и очищается после сохранения либо подтверждённой отмены редактирования. После восстановления черновика начинается новая история.

## Горячие клавиши

- `Ctrl/Cmd + Z` — отменить действие;
- `Ctrl/Cmd + Shift + Z` — повторить действие.

В текстовых полях эти сочетания не перехватываются приложением, поэтому работает нативная история браузера.

## Структура проекта

- `app/features/notes` — типы, история изменений и правила валидации заметок;
- `app/composables` — реактивная логика редактора заметки;
- `app/services` — работа с localStorage;
- `app/utils` — небольшие функции форматирования;
- `app/stores` — Pinia-store сохранённых заметок;
- `app/components` — переиспользуемые элементы интерфейса;
- `app/pages` — главная страница и редактор;
- `app/assets/styles` — общая SCSS-система;
